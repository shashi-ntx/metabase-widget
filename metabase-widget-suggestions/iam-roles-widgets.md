| 08  | Row 8      | Role create / Role update                       | How long do people spend on role creation?                                   | **Title:** Role Creation — Average Time Spent<br>**Description:** "How long do people spend on role creation?" Shows the average, median, min, and max time between starting and completing role creation.<br>**Tier:** Tier 3<br><br>**SQL:**<br>`sql<br>-- Snowflake-compatible<br>WITH start_events AS (<br>  SELECT SESSION_ID, TIMESTAMP AS START_TIME<br>  FROM NUSIGHTS_EVENTS_FLAT<br>  WHERE DESTINATION_NAME = 'create_role.newRole'<br>    AND PAGE_SECTION = 'Roles'<br>),<br>end_events AS (<br>  SELECT SESSION_ID, TIMESTAMP AS END_TIME<br>  FROM NUSIGHTS_EVENTS_FLAT<br>  WHERE DESTINATION_NAME IN ('Save Role', 'Exit Role Creation')<br>    AND PAGE_SECTION = 'form.create_role'<br>),<br>paired AS (<br>  SELECT s.SESSION_ID,<br>         s.START_TIME,<br>         e.END_TIME,<br>         TIMESTAMPDIFF('second', s.START_TIME, e.END_TIME) AS DURATION_SECONDS,<br>         ROW_NUMBER() OVER (PARTITION BY s.SESSION_ID ORDER BY e.END_TIME ASC) AS RN<br>  FROM start_events s<br>  JOIN end_events e<br>    ON s.SESSION_ID = e.SESSION_ID<br>    AND e.END_TIME > s.START_TIME<br>)<br>SELECT<br>  ROUND(AVG(DURATION_SECONDS) / 60, 1) AS AVG_MINUTES,<br>  ROUND(MEDIAN(DURATION_SECONDS) / 60, 1) AS MEDIAN_MINUTES,<br>  ROUND(MIN(DURATION_SECONDS) / 60, 1) AS MIN_MINUTES,<br>  ROUND(MAX(DURATION_SECONDS) / 60, 1) AS MAX_MINUTES,<br>  COUNT(*) AS TOTAL_SESSIONS<br>FROM paired<br>WHERE RN = 1<br>  AND DURATION_SECONDS > 0<br>  AND DURATION_SECONDS < 3600<br>`<br><br>**What this returns:** One row with average, median, min, and max time (in minutes) users spend creating a role.<br><br>**Assumptions:**<br>- Sessions lasting > 1 hour are outliers (likely abandoned tabs) and excluded<br>- Pairs the first valid end event after the start event within the same session<br><br>**Visualization:** Table (detail view). Time-between-events with multiple stats is best presented as a compact summary table.<br><br>**Grid size:** 12 × 7 | _No meaningful alternative — time-between-events analysis requires SQL for session pairing, and there's no simpler tier that can express this logic._                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
